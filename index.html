readline

Any link, turned into one an AI can actually open.

An Apple Music album, a paywalled-looking recipe, a feed, a JSON endpoint. readline fetches it, pulls out the title, the facts, the track list and the text, and hands back a link that serves all of it as plain HTML — which is the part a model can read.

    Open it

    Paste that into a chat. Nothing is stored — the link carries the original address inside it, so it works for anyone, and it stops working exactly when the original does.
